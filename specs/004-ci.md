# 004 — Integração contínua

Estado: workflow GitHub Actions implementado; execução remota pendente.

## Objetivo

Executar verificações repetíveis em pull requests e pushes para impedir regressões nos pacotes API e UI.

## Pipeline

- Instalar dependências com os lockfiles versionados.
- Executar ESLint nos fontes de API e UI.
- Gerar Prisma Client, executar testes unitários e compilar a API.
- Compilar a UI e validar o Compose.
- Construir as imagens de API e UI; não iniciar bancos ou publicar artefatos.

## Critérios de aceite

| ID | Cenário | Validação |
| --- | --- | --- |
| CI-01 | Workflow roda em push e pull request | Revisão do workflow |
| CI-02 | Lint, testes e builds API/UI passam no runner | Execução GitHub Actions |
| CI-03 | Compose valida e imagens API/UI constroem no runner | Execução GitHub Actions |

## Fora de escopo

Deploy, secrets de produção, smoke test com serviços, cobertura mínima, release e notificação externa.
